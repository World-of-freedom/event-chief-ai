# Alembic migrations

This directory is the only mechanism that changes the Supabase Postgres schema.
Starting FastAPI never runs `Base.metadata.create_all()` and never applies Alembic.

Run commands from `backend/` after activating the virtual environment and setting a
server-only `SUPABASE_CONNECTION_STRING` or `DATABASE_URL` in `backend/.env`.
`SUPABASE_URL` is only the HTTPS project URL; it is not a PostgreSQL connection.

```bash
alembic -c alembic.ini current
alembic -c alembic.ini upgrade head
alembic -c alembic.ini revision --autogenerate -m "describe_change"
alembic -c alembic.ini downgrade -1
```

Always inspect an autogenerated revision before committing it. Developers should
not modify an already-merged revision; create a follow-up revision instead.
